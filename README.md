# 🎮 Pac-Man Contributions

Pac-Man eats your GitHub contribution graph using **A\* pathfinding** — intelligently navigating every cell, eating all contributions, and completing the graph without ever getting stuck.

## Features

- ✅ A\* pathfinding with Manhattan distance heuristic
- ✅ Random target selection for unpredictable movement
- ✅ BFS fallback — guaranteed full coverage, never stuck
- ✅ Glowing trail + ghost followers
- ✅ Power pellets on high-contribution days
- ✅ Live HUD: Score, % Eaten, Cells Remaining
- ✅ Game Complete screen with Play Again
- ✅ Dark / Light theme toggle

---

## 🚀 Deploy in 3 Steps

### 1. Install dependencies

```bash
npm install
```

### 2. Run locally

```bash
npm run dev
```

Open http://localhost:5173

### 3. Deploy to Vercel

**Option A — Vercel CLI:**
```bash
npm install -g vercel
vercel
```

**Option B — GitHub + Vercel Dashboard:**
1. Push this folder to a GitHub repo
2. Go to https://vercel.com → New Project → Import repo
3. Click Deploy (auto-detects Vite, zero config needed)
